# Saad Farhan — Portfolio

Personal portfolio built with HTML, CSS, and JavaScript.

## Preview locally

Run from this folder:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Search and sharing metadata

Open Graph image: `og-image.png` (source: `og-image.html`, 1200 × 630).

After deployment, set the canonical URL, `og:url`, absolute `og:image` URL, and sitemap to the deployed address.
